\# Interior Design Project Manager (IDMS PRO)



A comprehensive Desktop ERP \& Database application built to streamline interior design project workflows, manage contractor assignments, and track furniture/fabric inventories.



\## 🛠️ Tech Stack

\* \*\*Frontend:\*\* Python (Tkinter GUI with Custom Dark Theme)

\* \*\*Backend Database:\*\* Oracle Database (XE)

\* \*\*Database Driver:\*\* `oracledb`



\## 📐 Database Architecture \& Lifecycle

\* Designed the system's \*\*ERD\*\*, converted it to a \*\*3NF Relational Schema\*\*, and executed \*\*DDL scripts\*\* on \*\*Oracle Database\*\* with a Python \*\*(Tkinter) CRUD GUI\*\*.

\* Implemented advanced database constraints including \*\*Manual Cascading Deletes (Set Null)\*\* to preserve structural financial and asset records.



\## 📁 Repository Structure

\* `/design`: Contains the Entity-Relationship Diagram (ERD) and official presentation.

\* `/database`: Contains the production-ready DDL SQL scripts (`schema.sql`).

\* `/src`: Contains the core Python application source code.
